# Anatomía del Scaffold (Unidad I)

**Qué hace:** Muestra las partes de un Scaffold: AppBar, body, botón flotante y barra inferior.

**Archivo principal:** `pantalla_principal.dart`

**Cómo ejecutarla:**
- En VS Code: pestaña *Run and Debug* (Ctrl + Shift + D) → elegir **"Unidad I · Anatomía del Scaffold"** → ▶
- O en la terminal:
```
flutter run -t lib/unidad1/anatomia_scaffold/main.dart
```
