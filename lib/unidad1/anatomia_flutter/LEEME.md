# Anatomía de Flutter (Unidad I)

**Qué hace:** Lista de elementos de ejemplo para conocer la estructura de una pantalla.

**Archivo principal:** `app_prueba.dart`

**Cómo ejecutarla:**
- En VS Code: pestaña *Run and Debug* (Ctrl + Shift + D) → elegir **"Unidad I · Anatomía de Flutter"** → ▶
- O en la terminal:
```
flutter run -t lib/unidad1/anatomia_flutter/main.dart
```
