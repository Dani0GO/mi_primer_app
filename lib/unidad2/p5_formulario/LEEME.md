# Práctica 5 – Formulario Interactivo (Unidad II)

**Qué hace:** Formulario de nombre y carrera que envía los datos a una segunda pantalla (Pantalla B).

**Archivo principal:** `formulario.dart`

**Cómo ejecutarla:**
- En VS Code: pestaña *Run and Debug* (Ctrl + Shift + D) → elegir **"Unidad II · Práctica 5 – Formulario Interactivo"** → ▶
- O en la terminal:
```
flutter run -t lib/unidad2/p5_formulario/main.dart
```
