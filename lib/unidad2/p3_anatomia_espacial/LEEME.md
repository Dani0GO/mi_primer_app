# Práctica 3 – Anatomía Espacial (Unidad II)

**Qué hace:** Pantalla dividida en 3 zonas: dos de altura fija y una flexible (Expanded).

**Archivo principal:** `pantalla_dimensiones.dart`

**Cómo ejecutarla:**
- En VS Code: pestaña *Run and Debug* (Ctrl + Shift + D) → elegir **"Unidad II · Práctica 3 – Anatomía Espacial"** → ▶
- O en la terminal:
```
flutter run -t lib/unidad2/p3_anatomia_espacial/main.dart
```
